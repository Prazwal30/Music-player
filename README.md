GEN-MUSIC
I made GEN-MUSIC as a simple place to listen to a few of my favorite songs. You can browse the Indie, Pop, and Love sections, pick a song, and play it right on the page.

What's inside
index.html is the home page.
indie.html, western.html, and love.html are the music pages.
about.html has a little more about the project.
mp3/ has the audio files, and cover photos/ and images/ have the artwork used on the site.
style.css contains the styles shared across the pages.
Run it
There isn't anything to install or build. Just open index.html in a browser and choose a section from the menu. You can also host the files as a static site, for example with GitHub Pages.

Making changes
To add or change a song, update the matching music page and make sure its audio and cover image paths point to files in this project. You can adjust the look of the pages in style.css.
